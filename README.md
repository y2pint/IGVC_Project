# 🏆 TNTech IGVC Project

Autonomous ground vehicle platform for the **Intelligent Ground Vehicle Competition (IGVC)**.
This project integrates NVIDIA **Isaac ROS (release-3.2)** for perception, mapping, and navigation, combined with **Nav2** and the **MPPI controller** for real-time autonomous driving.

The system is designed for **GPU-accelerated stereo vision, 3D mapping, and reactive navigation** on **Jetson AGX Orin**.

## 🎥 Sensor Configuration

```
     ↑
     │        [ ZED 2i ]
     │          (High Mount)
     │
     │        [ RealSense D435 ]
     │          (Low Mount)
     │
     └────────────────────────────→ Forward
```

| Sensor             | Purpose                               |
| ------------------ | ------------------------------------- |
| **ZED 2i**         | Long-range stereo depth, mapping, VIO |
| **RealSense D435** | Short-range RGB-D obstacle detection  |

Depth data from both sensors is fused by **NVBlox** into a unified voxel map and costmap for Nav2.

## 🚀 Running the Isaac ROS Dev Container (Fast Launch)

To avoid unnecessary Docker rebuilds and remote registry checks:

```bash
export SKIP_DOCKER_BUILD=1
export ISAAC_ROS_DISABLE_REMOTE_CHECK=1
igvc_ros_run
```

Or:

```bash
igvc_ros_run --skip_image_build
```

## ⚙️ System Setup

Refer to official Isaac ROS documentation:

* Isaac ROS Hardware Setup
* Jetson VPI Setup
* Development Environment Setup

Set the workspace path:

```bash
echo 'export ISAAC_ROS_WS=${HOME}/igvc2025/isaac_ros-dev' >> ~/.bashrc
```

Add a convenience alias:

```bash
echo "alias igvc_ros_run='cd \${ISAAC_ROS_WS}/src/isaac_ros_common && ./scripts/run_dev.sh -d \${ISAAC_ROS_WS}'" >> ~/.bashrc
source ~/.bashrc
```

## 🧩 Notes

* NVBlox **replaces the Nav2 obstacle layer** via `NvbloxCostmapLayer`
* ZED and RealSense can run **simultaneously**
* CAN-based motor control is preferred over USB for robustness
