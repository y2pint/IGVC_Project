# 🏆 Tennessee Tech IGVC Autonomous Vehicle Platform

This repository contains the **autonomous ground vehicle software stack** developed at **Tennessee Technological University** for the **Intelligent Ground Vehicle Competition (IGVC)**.

* **[`IGVC_RULES.md`](docs/IGVC_RULES_COMPLIANCE_2026.md)**

The system is built on **NVIDIA Isaac ROS (release 3.2)** and **ROS 2 Humble**, combining **GPU-accelerated stereo perception**, **3D mapping**, and **real-time navigation** using **Nav2 with the MPPI controller**, deployed on **Jetson AGX Orin** hardware.

---

## 🧠 System Overview

```
 ┌────────────────────────────────────────────────────────┐
 │                    IGVC System Stack                   │
 ├────────────────────────────────────────────────────────┤
 │  Sensors: ZED 2i (high) + RealSense D435 (low)         │
 │        │                                               │
 │        ▼                                               │
 │  Isaac ROS Image Pipeline / ZED Wrapper                │
 │        │                           │                   │
 │        └───────────────┬───────────┤                   │
 │                       ▼                                │
 │                Isaac ROS NVBlox (3D Map)               │
 │                       │                                │
 │                       ▼                                │
 │         NVBlox Costmap Layer → Nav2 (MPPI Controller)  │
 │                       │                                │
 │                       ▼                                │
 │                Vehicle Control Unit                    │
 └────────────────────────────────────────────────────────┘
```

**Key design principles**

* GPU-accelerated perception and mapping
* Unified 3D voxel representation for navigation
* Reactive local planning with MPPI
* Robust hardware communication (CAN over USB where possible)

## 🎥 Sensor Configuration

```
     ↑
     │        [ ZED 2i ]
     │          (High Mount)
     │
     │        [ RealSense D435 ]
     │          (Low Mount)
     │
     └────────────────────────────→ Forward
```

| Sensor             | Primary Role                                               |
| ------------------ | ---------------------------------------------------------- |
| **ZED 2i**         | Long-range stereo depth, mapping, visual-inertial odometry |
| **RealSense D435** | Short-range RGB-D obstacle detection                       |

Depth data from both sensors is integrated by **NVBlox** into a unified voxel map and exposed to **Nav2** through the `NvbloxCostmapLayer`.

## 🧭 Workspace Environment Setup

### Set the Isaac ROS workspace path

```bash
echo 'export ISAAC_ROS_WS=${HOME}/TnTechIGVC2026/isaac_ros-dev' >> ~/.bashrc
```

### Add a convenience alias for launching the dev container

```bash
echo "alias igvc_ros_run='cd \${ISAAC_ROS_WS}/src/isaac_ros_common && ./scripts/run_dev.sh -d \${ISAAC_ROS_WS}'" >> ~/.bashrc
source ~/.bashrc
```

## ⚙️ System Setup (Required)

This project requires **host-level configuration** in addition to the standard Isaac ROS Docker environment. Complete the following **in order**.

---

### 📘 Official Isaac ROS Documentation

Follow NVIDIA’s official setup guides for baseline configuration:

https://nvidia-isaac-ros.github.io/v/release-3.2/getting_started/index.html

* Isaac ROS Hardware Setup
* Jetson VPI Setup
* Isaac ROS Development Environment Setup

These cover:

* Jetson flashing and JetPack installation
* CUDA, TensorRT, and VPI configuration
* Docker and Isaac ROS base images

---

### 🧩 Project-Specific Setup Guides (Mandatory)

The following documents address **hardware, drivers, and communication layers** not covered by Isaac ROS:

* **[`UDEV_RULES.md`](docs/UDEV_RULES.md)**
  Host-side `udev` rules for:

  * Intel RealSense hot-plug recovery
  * Pixhawk USB devices
  * Non-root and Docker access on Jetson

* **[`VESC_CAN_SETUP.md`](docs/VESC_CAN_SETUP.md)**
  CAN bus setup for VESC motor controllers:

  * Jetson Orin AGX / Orin Nano CAN configuration
  * CAN IDs and termination
  * ROS 2 CAN integration and validation

* **[`ZED_SDK_HOST_Installation.md`](docs/ZED_SDK_HOST_INSTALLATION.md)**
  Native ZED SDK installation on Jetson:

  * Host-side installation (outside Docker)
  * Required system libraries
  * Verification with ZED tools

---

### ⚠️ Critical Notes

* These steps **must be performed on the host system**, not inside Docker
* Skipping host-level setup may result in:

  * USB device disconnects
  * CAN communication failures
  * ZED devices not visible inside containers

## 🚀 Launching the Isaac ROS Dev Container

To avoid unnecessary image rebuilds and remote registry checks:

```bash
export SKIP_DOCKER_BUILD=1
export ISAAC_ROS_DISABLE_REMOTE_CHECK=1
igvc_ros_run
```

Or equivalently:

```bash
igvc_ros_run --skip_image_build
```

## 🧩 Additional Notes

* NVBlox **replaces the Nav2 obstacle layer** via `NvbloxCostmapLayer`
* ZED and RealSense sensors can run **simultaneously**
* **CAN-based motor control** is strongly preferred over USB for robustness
