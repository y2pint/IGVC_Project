# 🏆️ IGVC Project

Autonomous ground vehicle platform for the **Intelligent Ground Vehicle Competition (IGVC)**.  
This project integrates NVIDIA’s **Isaac ROS** ecosystem for perception, mapping, and navigation with **Nav2** and the **MPPI controller**.  
Designed for **real-time navigation, mapping, and obstacle avoidance** using stereo vision and GPU-accelerated processing on **Jetson AGX Orin**.

---

## 🧠 System Overview

```
 ┌────────────────────────────────────────────────────────┐
 │                    IGVC System Stack                   │
 ├────────────────────────────────────────────────────────┤
 │  Sensors: ZED 2i (high) + RealSense D435 (low)         │
 │        │                                               │
 │        ▼                                               │
 │  Isaac ROS Image Pipeline → Isaac ROS Visual SLAM      │
 │        │                           │                   │
 │        └───────────────┬───────────┤                   │
 │                       ▼                                │
 │                Isaac ROS NVBlox (3D Map)               │
 │                       │                                │
 │                       ▼                                │
 │         NVBlox Costmap Layer → Nav2 (MPPI Controller)  │
 │                       │                                │
 │                       ▼                                │
 │                Vehicle Control Commands                │
 └────────────────────────────────────────────────────────┘
```

**Key Components**

| Subsystem | Function |
|------------|-----------|
| **Perception** | Stereo vision from **Intel RealSense D435** and **ZED 2i** |
| **Mapping** | **isaac_ros_nvblox** for voxel and costmap generation |
| **Planning & Control** | **Nav2 + MPPI** for smooth, reactive motion |
| **Localization** | Isaac ROS Visual SLAM or RealSense pose estimation |
| **Platform** | Jetson AGX Orin · Ubuntu 22.04 · ROS 2 Humble |

## 🎥 Sensor Configuration

```
     ↑ 
     │
     │        [ ZED 2i Camera ]
     │          (High Mount)
     │
     │        [ RealSense D435 ]
     │          (Low Mount)
     │
     └────────────────────────────────────────────────────────→  Ground (Forward)
```

| Sensor | Purpose | ROS Topics |
|---------|----------|------------|
| **ZED 2i** | Long-range mapping & obstacle detection | `/zed/zed_node/stereo/image_left`, `/zed/zed_node/depth/depth_registered` |
| **RealSense D435** | Short-range RGB-D mapping & local obstacle detection | `/camera/color/image_raw`, `/camera/depth/image_raw` |

NVBlox fuses both depth streams into a unified 3D voxel and costmap representation for Nav2.

# System Setup

Refer to the following guides to complete your system setup:

* [Isaac ROS Hardware Setup Guide](https://nvidia-isaac-ros.github.io/v/release-3.2/getting_started/hardware_setup/compute/index.html)
* [Jetson VPI Setup Guide](https://nvidia-isaac-ros.github.io/v/release-3.2/getting_started/hardware_setup/compute/jetson_vpi.html)
* [Development Environment Setup Guide](https://nvidia-isaac-ros.github.io/v/release-3.2/getting_started/dev_env_setup.html)

During the development environment setup, add the following line to your `.bashrc` file to define the Isaac ROS workspace path:

```bash
echo 'export ISAAC_ROS_WS=${HOME}/<this_repository_workspace>/isaac_ros-dev/' >> ~/.bashrc
```

You can also add an alias for quickly launching the development container:

```bash
echo "alias isaac_ros_run='cd \${ISAAC_ROS_WS}/src/isaac_ros_common && ./scripts/run_dev.sh -d \${ISAAC_ROS_WS}'" >> ~/.bashrc
```

After modifying `.bashrc`, reload it:

```bash
source ~/.bashrc
```

Finally, set up your sensors by following the [Isaac ROS Sensor Setup Guide](https://nvidia-isaac-ros.github.io/v/release-3.2/getting_started/hardware_setup/sensors/index.html).




## ⚙️ Build & Run

1. **Clone repository**
   ```bash
   git clone --recurse-submodules https://github.com/<your-org>/igvc_project.git
   cd igvc_project
   ```

2. **Install dependencies**
   ```bash
   sudo apt update
   rosdep update
   rosdep install --from-paths src --ignore-src -y
   ```

3. **Build**
   ```bash
   source /opt/ros/humble/setup.bash
   colcon build --symlink-install
   ```

4. **Run inside Isaac ROS Docker (recommended)**
   ```bash
   ./scripts/run_dev.sh
   ```

## 🧩 Notes & Tips

- Ensure both **`zed-ros2-wrapper`** and **`realsense2_camera`** drivers are installed and accessible inside Docker.  
- The `nvblox::nav2::NvbloxCostmapLayer` replaces the traditional obstacle layer in both **local** and **global** costmaps.  
- MPPI parameters (e.g., `mppi.yaml`) can be tuned for responsiveness, smoothness, and exploration behavior.  
- Use `rviz2` for visualization:
  ```bash
  rviz2 -d igvc_project/config/igvc_view.rviz
  ```
